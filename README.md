# opendevice-ddi

## 来源与声明

这些文件**来自 Apple 随 Xcode 发布的 Developer Disk Image**（macOS 上位于
`/Library/Developer/DeveloperDiskImages/iOS_DDI/`）。本仓库只是按 opendevice 需要的
结构存放它们，方便非 macOS 平台取用。

* 本仓库**不对其中 Apple 的文件主张任何权利**，也未对其内容做任何修改；
* 仓库自身的说明与脚本以 MIT 许可发布，**该许可不适用于其中的 Apple 文件**；
* 使用这些文件即视为你接受 Xcode 许可协议中与开发者磁盘镜像相关的条款，且**仅用于开发目的**；
* 若有许可顾虑，请直接从自己的 Xcode 安装中获取，不必使用本仓库；
* 如权利人提出要求，本仓库将立即下架（可开 issue 联系）。
